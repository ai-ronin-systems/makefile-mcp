# Changelog

## 0.1.0 — 2026-08-18

Initial release: safe Make discovery/exposure, typed variables, repository contexts, bounded process execution, process-tree timeout/cancellation, context file locking, normalized results, doctor, CLI, MCP stdio, capabilities, cache invalidation, examples, Docker and CI.

Before release, the implementation was flattened from the initial medium Clean Architecture scaffold to a KISS structure: the same behavior and safety boundaries remain, while use-case-per-file, ports-package, adapter-package and documentation hierarchy ceremony was removed.
